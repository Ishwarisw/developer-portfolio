# Developer Portfolio Dashboard

A modern, responsive, developer-style dark portfolio dashboard built with vanilla web technologies.

## 🚀 Overview
This project is built across a structured 3-day roadmap to showcase modern front-end web design and developer portfolio essentials.

### Day 1 Deliverables
- **Core Layout & Sections**: Sticky sidebar navigation, main header, hero section, skills grid, projects showcase, and contact footer.
- **Design System**: Dark developer theme (deep charcoal background `#0b0d14`, violet and purple accents `#8b5cf6` / `#a855f7`, frosted surface cards).
- **Navigation**: Smooth scrolling between sections, responsive mobile menu drawer, and active navigation indicators.
- **Version Control**: Git-tracked repository with clean commits and documentation.

## 🛠️ Technology Stack
- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`)
- **CSS3**: Modern Flexbox, CSS Grid, CSS Custom Properties (variables), responsive media queries
- **Vanilla JavaScript**: Lightweight DOM manipulation for mobile navigation toggling and smooth section scrolling
- **Git & GitHub**: Version control and repository hosting

## 💻 How to Run Locally
1. Clone this repository or download the source files:
   ```bash
   git clone https://github.com/<your-username>/developer-portfolio.git
   ```
2. Open `developer-portfolio/index.html` directly in your web browser (or use VS Code Live Server).
